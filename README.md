## 📌 Funciones de la app:
✅ Realizar recortes de pantalla en la zona seleccionada

✅ Al guardar la imagen puedes seleccionar los formatos jpeg, png y webp

✅ Permite comprimir la imagen, para reducir el tamaño

## 📌 Tecnologías
- Python 3.10.7
- altgraph 0.17.5
- packaging 26.1
- pefile 2024.8.26
- pillow 12.2.0
- pyinstaller 6.19.0
- pyinstaller-hooks-contrib 2026.4
- pywin32-ctypes 0.2.3


## 📌 Instalación
1. Clonar o descargar el repositorio
2. Tener instalado Python
3. Aplicar el comando pip install -r requirements.txt
4. Ejecutar el archivo app.py
